# Trovixo — запуск исправленной версии

## Что исправлено

В присланном архиве настройки Shopify находились в `.env.example`. Next.js не читает этот файл. Из-за отсутствия `.env.local` вместо настоящего товара показывался демонстрационный продукт. Рабочие настройки перенесены в `.env.local`; `.env.example` теперь служит шаблоном без токена. Не копируйте его поверх включенного `.env.local`.

Настроен товар `trovixo-multicolor-car-christmas-lights`, Shopify ID `7935482822715`. Коллекция не требуется. Цена, наличие, фотографии и варианты загружаются из Shopify. Демонстрационный режим включается только явным `STOREFRONT_PREVIEW=true` при отсутствии Shopify.

Технические кнопки покупки и корзина управляются `NEXT_PUBLIC_STORE_LAUNCH_ENABLED`. В этой локальной копии он включен. Реквизиты продавца и одобрение юридических текстов проверяются отдельно; их отсутствие не подменяет товар заглушкой. Пока они не заполнены, страницы политик помечены черновиками, а поисковая индексация выключена.

## Запуск на Mac

В терминале внутри папки `project` выполните:

```sh
npm ci
npm run check:shopify
npm run dev
```

Откройте http://localhost:3000. Проверьте товар, добавление в корзину и кнопку перехода к checkout. Команда `check:shopify` не выводит значение токена.

Для production:

```sh
npm run build
npm start
```

После изменения `.env.local` перезапустите dev-сервер; production пересоберите.

## Хостинг

Это Next.js headless storefront, а не Liquid theme. Размещайте приложение на Node-совместимом хостинге. В панели хостинга заполните переменные из `.env.local`, измените `NEXT_PUBLIC_SITE_URL` на ваш настоящий HTTPS-домен и выполните новую сборку. Headless в Shopify предоставляет API-доступ, но не размещает этот Next.js проект.

## Данные, которые нельзя придумать

Перед реальными продажами заполните `NEXT_PUBLIC_BUSINESS_NAME`, `NEXT_PUBLIC_BUSINESS_ADDRESS`, `NEXT_PUBLIC_BUSINESS_COUNTRY`, проверьте рабочий support email, утвердите фактические условия доставки и возвратов и заполните соответствующие страницы в `app/`. Добавьте эти политики также в Shopify Admin. После проверки выставьте `POLICIES_APPROVED=true` и пересоберите сайт.

Проверьте в Shopify способы оплаты, доставку в США, налоги и уведомления. Получите подтверждение поставщика о составе набора, остатках, отправке из США и сроках. Успешное получение checkout URL подтверждает интеграцию сайта, но не подтверждает успешную оплату или выполнение заказа. Тестовую оплату следует выполнить через тестовый режим вашего платежного провайдера.

В `.env.local` сохранен предоставленный вами public Storefront token. Приватный Admin API token для сайта не используется. Не загружайте свой `.env.local` в публичный репозиторий.
